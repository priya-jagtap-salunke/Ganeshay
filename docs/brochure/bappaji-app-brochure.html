First day — setup in 10 minutes

2

एकदाच Settings save करा, नंतर दररोज Home वरूn New Booking आणि Tele-Messaging वापरा. Internet + WhatsApp installed असणे आवश्यक.

  1. Login Vendor email/password ने login. Account pending असल्यास admin approval थांबा.
  2. Settings → Business details नाव, phone, address, Map link, Instagram, website. Logo upload करा → Save Settings.
  3. WhatsApp messages Tele-calling message (Send details) आणि Review & Request message edit / Reset to Default.
  4. Test booking Home → New Booking → Save → Share receipt/PDF on WhatsApp → OK. पुढची booking blank form मध्यe उघडते.
  5. Import contacts (optional) Tele-calling किंवा Tele-Messaging → Excel / phone import. Same list दोन्ही features साठी.

Tele-calling & Tele-Messaging

4

📞 Tele-calling — steps

1) Import Excel / phone / call log  →  2) Tap contact  →  3) Call or Send details (Settings मधील message)  →  4) Status update (Called / Call back).

💬 Tele-Messaging — steps

1) Pending tab  →  2) Send  →  Send details (Sent मध्यe जातo) किंवा Review & Request (Google review link + Instagram)  →  3) Sent tab मध्यe track करा.

📥 Import Contacts (full page)

Sample Excel download → Name + Mobile भरा → Upload → Preview मध्यe valid/invalid पहा → Import. Tele-calling & Tele-Messaging दोन्हीला same contacts.

Do ✅ / Don’t ❌

✅ Do

Settings save after change. WhatsApp share आधी mobile तपासा. Reports → Excel backup.

❌ Don’t

Tele-Messaging “Delete all contacts” without backup. Login share करू नका.
